## User story

As the kernel, I want every byte the syscall path copies out of (or into) a userspace buffer to be resolved through the **task's own `TTBR0_EL1` translation tables** and confirmed `USER`-accessible before any dereference — so that a real EL0 task holding a debug-console capability **cannot** pass an in-window high-half kernel VA and have the kernel copy privileged memory to the console (the confused-deputy read [phase-b §B6 gate #1](../../../roadmap/phases/phase-b.md#t-021-carry-forward-gates-must-close-before-a-real-el0-task-runs) names). Today the copy is a bounds-checked int-to-pointer dereference that proves *range*, not *ownership*.

## Context

[T-021](T-021-syscall-dispatch.md) (B5) built the syscall copy path against an EL1 kernel-stub proxy: [`copy_from_user`](../../../../kernel/src/syscall/user_access.rs) validates `[ptr, ptr+len)` against a single [`UserAccessWindow`](../../../../kernel/src/syscall/user_access.rs) and then dereferences `user_ptr as *const u8` — sound only because the stub runs in the bootstrap AS (kernel identity-reachable) and `EPD0 = 1` keeps real EL0 out of `syscall_entry`. [ADR-0009 §Open questions](../../../decisions/0009-mmu-trait.md) deferred the translation-walk query "*until a concrete caller needs it*"; B6 gate #1 is that caller. T-025 lands the **mechanism** (the trait query + the translate-based copy-user) — fully host-testable against `FakeMmu`, **without** a real EL0 task. Sourcing the per-task window + the running task's address space/capability table into `syscall_entry` is gate #3 ([T-026](T-026-current-task-cap-table.md)); the runtime EL0 round-trip is the later B6 wire-up.

## Acceptance criteria

- [ ] **`Mmu::translate`** ([`hal/src/mmu/mod.rs`](../../../../hal/src/mmu/mod.rs)): `fn translate(&self, as_: &Self::AddressSpace, va: VirtAddr) -> Result<(PhysFrame, MappingFlags), MmuError>` — a **read-only** walk (no `FrameProvider`, no mutation) returning the `PAGE_SIZE`-aligned frame backing `va` + the leaf `MappingFlags`; `MmuError::NotMapped` for an absent leaf, `MmuError::BlockMapped` for a block-descriptor hit (v1 serves only 4 KiB page leaves). Documented as the realised ADR-0009 walk query.
- [ ] **`vmsav8::descriptor_bits_to_flags`** ([`hal/src/mmu/vmsav8.rs`](../../../../hal/src/mmu/vmsav8.rs)): `pub const fn descriptor_bits_to_flags(desc: u64) -> MappingFlags` — the inverse of `flags_to_descriptor_bits`, **lock-shut** (reconstructs only the five named flags from `AP[7:6]`/`UXN`/`PXN`/`AttrIdx[4:2]`/`nG`; an unrecognised bit pattern never widens). Round-trip host-tested against `flags_to_descriptor_bits` over every named-flag combination.
- [ ] **`QemuVirtMmu::translate`** ([`bsp-qemu-virt/src/mmu.rs`](../../../../bsp-qemu-virt/src/mmu.rs)): a read-only L0→L3 walk reusing the existing walker, decoding the leaf via `PAGE_OA_MASK_L3` + `descriptor_bits_to_flags`; block hit → `BlockMapped`, invalid → `NotMapped`. **UNSAFE-2026-0025 Amendment** (read-only walk; no new entry).
- [ ] **`FakeMmu::translate`** ([`test-hal/src/mmu.rs`](../../../../test-hal/src/mmu.rs)) + any other test `Mmu` impls: page-aligned map lookup → `(PhysAddr→PhysFrame, MappingFlags)`, `NotMapped` on miss.
- [ ] **Translate-based copy-user** ([`kernel/src/syscall/user_access.rs`](../../../../kernel/src/syscall/user_access.rs)): `copy_from_user` / `copy_to_user` become generic over `<M: Mmu>`, take `mmu: &M` + `task_as: &M::AddressSpace`; the int-to-pointer dereference is replaced by a per-page loop — `translate` each spanned page, **require `MappingFlags::USER`** (and `WRITE` for `copy_to_user`), rebase via `phys_frame_kernel_ptr` + in-page offset, copy the page sub-run. Any `translate` error or missing `USER` → `SyscallError::FaultAddress`, **nothing copied observable** (all-or-nothing). The copy **contract** (zero-length short-circuit, `FaultAddress` on failure) is unchanged. **UNSAFE-2026-0030 Amendment**.
- [ ] **`SyscallContext`** ([`kernel/src/syscall/dispatch.rs`](../../../../kernel/src/syscall/dispatch.rs)) becomes generic over `<'a, M: Mmu>` with `mmu: &'a M` + `task_as: &'a M::AddressSpace`; `sys_console_write` threads them into the copy. The dispatcher stays panic-free and otherwise unchanged.
- [ ] **Per-task `UserAccessWindow`** derived from `[entry_va, stack_top_va)` (the `LoadedImage` span) — a cheap *first gate* (range/wrap/zero-length), no longer the RAM extent. A helper computes it; `translate`'s `USER` check is the load-bearing boundary.
- [ ] **Host tests** (the §Simulation row-to-verification mapping of [ADR-0038](../../../decisions/0038-mmu-translate-and-user-access.md)): `copy_from_user_translates_and_copies_a_user_page`; `copy_from_user_rejects_in_window_kernel_only_page` (confused-deputy regression); `copy_from_user_faults_on_unmapped_page`; `console_write_cap_ok_but_kernel_page_emits_nothing`; `console_write_multipage_second_page_unmapped_emits_nothing`; `copy_to_user_rejects_read_only_user_page`; retained `UserAccessWindow::validate` wrap/zero-length tests; `descriptor_bits_to_flags` round-trip + a kernel-only descriptor decoding **without** `USER`.
- [ ] **All gates green:** host tests (+N), host + kernel clippy `-D warnings`, `cargo fmt --check`, kernel build, `cargo +nightly miri test --workspace --exclude tyrne-bsp-qemu-virt` (the exposed-provenance copy-user pattern keeps the now-translation copy sound). **QEMU smoke:** see §Approach — the B5 `+0x200` stub smoke **changes** (its kernel-VA buffer is now correctly rejected), so the trace is **not** byte-stable; the dormant smoke is re-seeded or repurposed to demonstrate the `FaultAddress` rejection. Documented in the PR.

## Out of scope

- **Sourcing the per-task window + the running task's capability table into `syscall_entry`** — that is gate #3 / [T-026](T-026-current-task-cap-table.md). T-025 builds the mechanism + threads `mmu`/`task_as` through `SyscallContext`; the BSP wiring that picks *which* task's AS lands in T-026.
- **Running a real EL0 task** — the B6 wire-up (after T-025 + T-026).
- **A `change_flags` / per-page-update path, huge-page or block translate** — `translate` serves 4 KiB page leaves only (block → `BlockMapped`); the loader maps user pages page-granular.
- **`copy_to_user` callers** — no v1 syscall returns via a user pointer (recv returns in registers); `copy_to_user` is rewritten + tested for symmetry/future use, not wired to a syscall.

## Approach

Compose ADR-0038's chosen shape (Option 1). Build inside-out so each layer is testable as it lands: (1) `vmsav8::descriptor_bits_to_flags` + round-trip tests; (2) `Mmu::translate` on the trait + `FakeMmu` impl + `QemuVirtMmu` read-only walk; (3) the translate-based `copy_from_user`/`copy_to_user` + `SyscallContext` generic-ification + the confused-deputy host tests; (4) per-task window helper. The whole boundary is proven on the host against `FakeMmu`/a fake address space — no QEMU, no EL0 — because `translate` over a flat map is deterministic and the copy logic is pure over the context.

**Known interaction — the B5 `+0x200` stub smoke.** Post-T-022 the kernel runs high-half; the B5 EL1 stub's `console_write` buffer is a **kernel** high VA (`.rodata` greeting). Under the new `USER`-enforcing translate path that buffer is correctly **rejected** (`FaultAddress`) — exactly the confused-deputy defence. So the dormant smoke is no longer byte-stable. Resolve during implementation (decide at the start, record in the PR): either (a) **repurpose** the stub smoke to demonstrate the rejection (`console_write` of a kernel VA → `FaultAddress`, fault-clean) — a *positive* demonstration that gate #1 works; or (b) **re-seed** the stub with a small `USER`-mapped buffer in a throwaway AS so a positive copy still runs. Option (a) is preferred (it directly exercises the new boundary and needs no contrived AS). This is a smoke-trace change, not a regression; the real positive EL0 round-trip is the B6 wire-up.
